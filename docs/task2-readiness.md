# Task 2 AI 股票问答准备合同

## 启动条件

Task 2 只有在新版 `T1-EXPERIENCE` 进入 `VERIFIED` 后才开始。它复用届时已验证的新行情模型、详情路由和图表接口；不得引用 `archive/task1-v1/` 的实现。

## 固定切片顺序

1. `T2-000`：Android/H5 最小聊天页。
2. `T2-VERTICAL`：消息模型、确定性 Mock Chat、发送状态和结构化内容首个切片。
3. `T2-EXPERIENCE`：Markdown、长会话、失败重试、行情卡片/图表承接和跨端体验。

Task 1、Task 2 使用同一 Codex 主开发和四门验收管线；OpenCode 仅作经用户确认的备选。

## 内容合同

- 会话使用角色、状态、消息和显式内容块模型；结构化行情不从 Markdown 反解析。
- Markdown、行情卡片、趋势图和 Notice/Error 是独立类型。
- Provider 默认离线、确定性，不接真实模型、实时行情、联网检索、登录或云同步。
- 原始 HTML、脚本、远程图片和未确认外链不得自动执行。
- 结构化内容的点击只调用新版 Task 1 已验证的路由和实体模型。

## 状态与验收

- 提交非空问题后追加用户消息和发送中占位；成功原位替换，失败提供重试。
- 覆盖空输入、重复发送、成功/失败/重试、未知代码、内容块顺序、免责声明和长会话滚动。
- Android/H5 依赖、编译、bundle、浏览器交互和设备运行分别记录。
- 四门未齐不得进入 `VERIFIED`。
