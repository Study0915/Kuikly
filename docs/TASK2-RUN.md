# Task 2 · 证据问答使用说明

从行情首页点“打开证据问答”，或打开 `/?page=chat`。这是 Kuikly 共享代码实现的离线原型，支持示例股票 A–L；所有回答来自规则模板与可计算的历史 Mock 事实，没有真实模型或行情接口。

## 启动与体验

```powershell
.\scripts\doctor.ps1
.\scripts\verify.ps1
.\scripts\run-h5.ps1 -Production
```

本地入口：[行情与问答](http://127.0.0.1:18761/)。工具/SDK准备与工作区约束见[Task 1说明](TASK1-RUN.md)。没有全局安装或系统PATH修改。

1. 输入“分析 A 的走势”并发送，查看 Markdown 摘要和行情证据卡。
2. 点“A · 核对中途回落”，详情直接选中 08-24 至 08-27 的 -6.09%；查看计算式、端点与双图。点返回问答，原消息、草稿和滚动位置仍在。
3. 输入“比较 A 和 B”，同一组件显示 A 的 +12.00%/1.50倍与 B 的 -4.00%/0.80倍。两者都是相同20日窗口、各自分母。
4. 点“追问 B 风险”，无需重新输入股票，回答仍绑定 B。点“检验 B 缺量”，09-02成交量缺失使倍数不可用，价格依据仍可用。进入详情后仍是缺量快照。
5. 展开走势图，点某个交易日进入详情，返回保留这条消息的展开状态。拖动图表用于滚动，不会误入详情。
6. 底部“正常演示”可切为“首次失败”，发送后点重试；原问题原位恢复。回答生成期间可以取消，再重试或新会话。
7. 输入未知股票会返回支持范围，不生成虚假卡片。最多500字、20轮；达到上限保留已有记录，点新会话重新开始。

## 保存与边界

会话仅保存在本次页面生命周期中，刷新/重启会清空。返回行情再进入、详情来回与浏览器前进后退保留当前会话；分享地址只包含行情位置，不包含问题。没有云同步、登录、交易、真实预测或远程Markdown资源。

Markdown支持标题、段落、列表、引用、粗体、行内代码及代码围栏；不支持完整CommonMark表格或可点击外链。HTML以文字显示，图片和链接只显示标签。

H5有真实浏览器运行证据；Android Debug APK构建通过。Android设备/键盘、iOS、鸿蒙未运行验证。较小H5视口检查不能代替手机系统键盘测试。
