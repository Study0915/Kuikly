## 课程说明

本项目基于 Kuikly 实现股票行情浏览、证据联动详情，以及支持 Markdown 和行情卡片的问答功能，完成 Task 1 与 Task 2。两题复用证据计算、走势图与详情组件，支持结论、区间和交易日之间的双向核对，以及带上下文的追问和缺量处理。行情与回答采用确定性历史 Mock，已验证 H5 交互与 Android 构建；项目 README 提供运行说明、演示视频和测试证据。
