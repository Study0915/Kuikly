# T1-000 学习报告 · Task 1 reset scaffold

## 目标

把旧 Task 1 与活动构建隔离，并建立一个能在 Android/H5 编译和运行的最小起点。该空壳不包含行情、图表或 AI 业务实现。

## 调用链

```text
Android MainActivity / H5 main
  → Kuikly delegator attach("finance_home")
  → KSP 注册的 Task1ShellPage
  → View/Text 渲染 reset、Mock、未验证和免责声明
```

## 状态变化

- 变更前：`finance_home`、`stock_detail`、旧图表和 Provider 属于活动构建。
- 变更后：旧实现进入 `archive/task1-v1/`；活动入口只剩 `finance_home` 空壳。
- 后续：`T1-VERTICAL` 通过新任务卡定义行情模型、Provider、详情路由和基础图表，不继承旧 API。

## 关键 Kuikly API

- `@Page(..., supportInLocal = true)`：把共享 Pager 注册为跨端页面。
- `Pager.body()`：返回共享 UI 树。
- Android/Web delegator：宿主把容器、页面名和 Mock 标记交给 Kuikly runtime。

## 设计原因

- 保留相同模块名和 `finance_home` 入口，使现有 Gradle、CI 和宿主门禁仍可运行。
- 删除活动业务 API，避免“归档了源码但仍暗中复用旧实现”。
- 归档保留 Git 基线、源码和证据，同时通过 settings/CI 隔离。
