# Task 1 重新开发准备合同

## 起点

活动工程从 `finance_home` 跨端空壳开始。旧版图表、行情模型、Provider、页面和路由只存在于 `archive/task1-v1/`，不提供兼容合同，也不计入新版完成度。

## 固定切片顺序

1. `T1-000`：Android/H5 空壳、环境和证据基线。
2. `T1-VERTICAL`：新行情模型、确定性 Mock Provider、行情列表、详情路由和最小趋势图形成端到端路径。
3. `T1-EXPERIENCE`：完整图表交互、Mock AI 解读、加载/空/错误/重试状态和跨端体验。

每个切片由 Codex 建任务卡、实现并通过四门；不得在一个切片中顺手完成后续范围。

## 设计合同

- 新公开模型和接口在 `T1-VERTICAL` 任务卡中定义；不以旧类型名或签名作为兼容要求。
- Provider 默认读取仓库内确定性 fixture，不联网、不读取密钥。
- 图表计算、数据清洗和命中测试与 Canvas/UI 分离。
- 路由参数显式校验，未知代码进入可恢复错误状态。
- 页面始终展示 Mock 标签和“仅作技术演示，不构成投资建议”。

## 验收门禁

- 单测覆盖当前切片的正常、空、错误和边界状态。
- 每次执行 `scripts\verify.ps1`；H5 production bundle 与浏览器交互分别留证。
- Android 未在真机/模拟器运行时只声明 APK 构建通过。
- 学习报告必须链接实际文件、命令和证据，并提供 5 道面试题。

## 失败升级

Codex 连续两次获得相同可复现失败，或缺少 Windows 无法提供的必要环境时，将任务置为 `BLOCKED`。只有用户确认后才生成 OpenCode 备选 handoff。
