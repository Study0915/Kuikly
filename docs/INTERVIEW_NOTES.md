# Kuikly 面试与口述学习记录

本文件记录用户对每个模块的理解，不代替 `docs/learning/` 中的技术报告。

## 使用规则

- 每个 Feature 由实现 Agent 提供 5 道问题，Codex 检查问题是否覆盖调用链、状态、跨端和取舍。
- 用户先脱离代码口述，再把简短答案记录到本文件。
- 讲不清的部分创建补充学习任务；不得用复制源码代替理解。
- 每周至少一次 10 分钟项目口述：产品目标、模块边界、一次点击后的调用链、当前限制和下一步。
